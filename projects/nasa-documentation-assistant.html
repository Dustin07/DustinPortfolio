Project Context

During my internship at NASA Marshall Space Flight Center, I developed a Raspberry Pi documentation assistant for laser directed energy deposition (LDED) documentation and manuals.

This was a separate project from my real-time manufacturing monitoring system. The assistant addressed document queries; the monitoring system addressed live process sensing and physical feedback.

Documentation Approach

The assistant used a local language model and retrieval-augmented generation (RAG) to query LDED documentation and operating manuals. Retrieval connects a question with relevant source material, giving the language model task-specific context.

Engineering Decisions

  • Use relevant source material: Connect document queries with manufacturing documentation and manuals through retrieval-augmented generation.
  • Run the language model locally: Use a Raspberry Pi as the platform for the documentation assistant.
  • Keep the system’s purpose clear: Treat document access as its own workflow, distinct from live sensing and operator feedback.

Tools & Methods

  • Raspberry Pi
  • Local language model (LLM)
  • Retrieval-augmented generation (RAG)
  • LDED documentation and operating manuals

What I Learned

I learned to connect a language model to the information needed for the task. For manufacturing documentation, retrieving relevant source material is a central part of the query workflow. This project also reinforced the distinction between a documentation assistant and a live process-monitoring system.
